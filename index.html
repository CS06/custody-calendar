Custody Calendar Help

Read the calendar

Choose a child, then use Month, Week, or Day to see their schedule. Tap a date to open its details. The legend shows which color belongs to each parent. A split day has a handoff, with the time shown in the day details.

Set the regular schedule

In Settings, choose the child whose schedule you want to edit. Set the start date and usual handoff time, then assign each weekday in Week A. Turn on Alternate weeks to use Week B every other week. The rotation starts on the schedule start date. Save your changes before leaving Settings.

Add holidays and one-time changes

Use Holidays for recurring exceptions. You can assign different parents in even and odd years and set start and end times. Use One-Time Changes for a swap or trip on specific dates. One-time changes take priority over holidays, and holidays take priority over the regular schedule. If two entries of the same type overlap, the first listed entry wins.

Mark days off

Add No school, Off work, or Vacation for a date or range. These labels leave custody assignments intact. No school starts with the current child selected. Off work and Vacation start with All children selected, which also covers children you add later. Use Applies to to choose who sees an entry. Turn on yearly repeat for dates that stay the same each year.

Manage children and appearance

Use Children in Settings to add, rename, or remove a child. Each child has their own custody schedule. Use Appearance to change the parent colors, or the theme button in the main header to switch between light and dark.

Print the month

Use Print current month in Settings to print the selected child's month or save it as a PDF.

Import and export backups

Your calendar data is stored in this browser. To make a backup or move it to another device, use Export in the main header. Select the children to include, choose whether to include appearance colors, then choose Download PNG backup or Download JSON backup. Send the JSON as a file when sharing through a messaging app, since some apps strip backup data from images.

To restore a backup, use Import in the main header and choose a Custody Calendar PNG or JSON backup. Choose what to restore. Merge adds the children in the backup as new entries and keeps existing children. Replace all removes the existing children and schedules and restores those in the backup.

Keep backups private. The PNG contains schedule data beyond what's visible in the image. Export a backup before clearing browser data or using Reset app data.
